COMPONENT LENS 1.1.0 — Portable for Windows x64

FR : Décompressez le ZIP, puis lancez ComponentLens.exe. Le navigateur s'ouvre.
Gardez la console ouverte. Connectez les deux workspaces avec leurs URL et tokens
API, puis recherchez les doublons. Choisissez FR, EN ou ES en haut à droite.
Les connexions et la comparaison sont sauvegardées localement, chiffrées pour
votre compte Windows. Le redémarrage les restaure sans nouvelle analyse.
Fermez la console ou cliquez sur Quitter pour arrêter l'application.

EN: Extract the ZIP and run ComponentLens.exe. Your browser opens automatically.
Keep the console open. Connect both workspaces with their URLs and API tokens,
then find duplicates. Choose FR, EN or ES at the top right. Demo needs no tokens.
Connections and the latest comparison are saved locally, encrypted for your
Windows account, and restored at startup without a new scan. Quit to stop.

ES: Extrae el ZIP y ejecuta ComponentLens.exe. El navegador se abre automáticamente.
Mantén abierta la consola. Conecta ambos workspaces con sus URL y tokens de API
y busca duplicados. Elige FR, EN o ES arriba a la derecha. La demo no necesita
tokens. Las conexiones y la comparación se guardan localmente, cifradas para tu
cuenta de Windows, y se restauran al iniciar. Cierra la consola o pulsa Salir.

Requires Windows 10/11 x64, a modern browser and Altium 365 API access.
No Node.js, .NET or Altium Designer installation needed. The embedded .NET runtime
may unpack native files into the temporary directory. This build is unsigned.
Only visible library data can be compared; partial reports are clearly marked.
Read-only: this app never modifies Altium data.

Saved data: %LOCALAPPDATA%\ComponentLens\state.dat (Windows DPAPI, current user).
Local data menu: forget saved connections and comparison, including the backup.
All duplicate groups appear on one page. Demo data is not saved as a real result.
When upgrading from 1.0.x, enter your two tokens once; old releases did not save them.

Documentation: see the GitHub repository README and docs/VALIDATION.md.
